# Стандарты публикации модов в Thunderstore и совместимости с r2modman

Этот документ подробно описывает требования платформы Thunderstore и менеджера модов r2modman для сообщества Valheim. Соблюдение этих правил гарантирует, что мод будет успешно принят системой проверки, корректно отображаться в поиске и автоматически устанавливаться пользователями без ошибок.

---

## 1. Структура архива `.zip` для загрузки

Для Valheim (игры на BepInEx) Thunderstore ожидает плоскую или стандартную структуру архива:

```text
PingMaker_v1.0.0.zip
├── manifest.json       (Обязательно)
├── icon.png            (Обязательно, ровно 256x256 пикселей)
├── README.md           (Обязательно)
├── CHANGELOG.md        (Рекомендуется)
└── PingMaker.dll       (Скомпилированный плагин)
```

> ⚠️ **Критически важное правило упаковки:**
> При создании `.zip` архива **ни в коем случае нельзя упаковывать родительскую папку**. 
> Файлы `manifest.json`, `icon.png`, `README.md` и `.dll` должны находиться **прямо в корневом каталоге архива**! 
> Если внутри архива окажется папка вроде `PingMaker/...`, r2modman не сможет правильно определить тип мода.

При установке мода с такой корневой структурой r2modman автоматически:
1. Создает каталог `BepInEx/plugins/PingMaker/` в профиле пользователя.
2. Помещает туда `.dll` и сопутствующие файлы.

## 2. Спецификация файла `manifest.json`

Файл `manifest.json` валидируется строгим JSON-парсером Thunderstore:

```json
{
  "name": "PingMaker",
  "version_number": "1.0.0",
  "website_url": "https://github.com/YourUsername/PingMaker",
  "description": "Multiplayer 3D world ping system with radial color wheel, creature silhouette highlighting, distance counter, and off-screen pointers.",
  "dependencies": [
    "denikson-BepInExPack_Valheim-5.4.2202"
  ]
}
```

### Поля и валидация:
1. **`name`**:
   - Формат: только символы `a-z`, `A-Z`, `0-9` и знак подчеркивания `_`.
   - **Запрещено:** пробелы, дефисы `-`, спецсимволы, кириллица.
   - Длина: до 64 символов.
2. **`version_number`**:
   - Строгий SemVer: `MAJOR.MINOR.PATCH` (например: `1.0.0`, `1.2.3`).
   - **Запрещено:** префиксы вроде `v1.0.0` или суффиксы `-beta`.
   - При каждом обновлении мода номер версии обязан увеличиваться.
3. **`website_url`**:
   - Должен быть валидным URL-адресом (например, ссылка на GitHub-репозиторий или страницу мода). Поле не может быть пустым.
4. **`description`**:
   - Краткое описание функционала.
   - **Жёсткий лимит:** строго **до 250 символов**! Превышение даже на один символ приводит к мгновенной ошибке загрузки на Thunderstore.
5. **`dependencies`**:
   - Массив зависимостей в формате `Автор-НазваниеПакета-Версия`.
   - Для модов Valheim обязательной базовой зависимостью является `denikson-BepInExPack_Valheim-5.4.2202`.

## 3. Требования к `icon.png`

* **Разрешение:** Строго **256x256 пикселей**. Изображения любого другого разрешения (например, 512x512 или 128x128) отклоняются загрузчиком.
* **Формат:** Стандартный PNG (8-bit или 24/32-bit RGBA).
* **Стиль:** Квадратная форма, контрастный читаемый логотип.

---

## 4. Оформление `README.md`

`README.md` отображается на главной странице мода в Thunderstore и внутри r2modman. Рекомендуется включать следующие разделы:
1. **Заголовок и краткое саммари:** Что делает мод в 1-2 предложениях.
2. **Ключевые возможности (Features):** Маркированный список (3D-пинг, круговое меню, подсветка существ, синхронизация в мультиплеере).
3. **Управление (Controls):** Назначенные клавиши по умолчанию (Middle Click, Hold).
4. **Конфигурация (Configuration):** Описание параметров в `.cfg` файле.
5. **Установка (Installation):** Инструкции для r2modman и ручной установки.
6. **Совместимость в мультиплеере (Multiplayer):** Работает ли мод, если он установлен только у части игроков (в нашем случае маркеры видят те, у кого стоит мод; игра не крашится при отсутствии мода у других игроков).
